01 · Target 변경 시 등록 원재료를 한 번 적용

자동 기본값과 수동 선택 후보의 역할 분리
관점AS-IS · 기준 코드TO-BE · 구현 결과
자동 선택 근거프로파일 등록 원재료와 과거 사용 이력을 합친 후보가 자동 선택 판단에도 쓰임.유효한 등록 원재료만 판단. 1개이면 적용, 여러 개이면 원재료를 비워 직접 선택, 0개이면 현재 원재료 유지.
적용 시점이전에 수동 선택한 원재료가 있으면 새 Target으로 바꿔도 등록 기본값 적용이 막힘. 후보 갱신에 따라 적용을 재시도.다른 Target을 명시적으로 선택할 때 생성한 요청을 한 번 소비. 이력 후보는 수동 선택용으로 유지.
늦은 응답선택 세대별 요청 식별 없이 후보 준비 여부를 확인.프로파일·워크스페이스·요청 객체가 일치해야 적용. 수동 변경, Charge, 작업공간 전환, 생산 계획 인계는 대기 요청을 무효화.
사용 예 Target A의 등록 원재료가 생두 A이고 이력에 생두 B가 있어도 A를 자동 적용합니다. 이후 생두 C를 직접 고르면 재조회·재마운트가 C를 되돌리지 않습니다. 그다음 Target B를 명시적으로 선택하면 B의 새 등록 기본값을 한 번 적용합니다.

생산 계획 인계(handoff)의 원재료와 이미 Charge한 배치의 선택은 비동기 자동 기본값으로 바뀌지 않습니다. 초기 Target 복원·같은 Target 재선택·Target 해제에는 새 자동 적용 요청을 만들지 않습니다.

02 · 같은 저장 곡선을 같은 표시 기준으로

히스토리와 프로파일 상세의 변화
화면AS-IS · 기준 코드TO-BE · 구현 결과
히스토리리포트 모드와 샘플 기반 온도 축 보정 사용. ET RoR 표시를 끄고 제어 그래프 비율을 고정.현재 온도·RoR 축, 단위, 채널, 이벤트 스타일, 단계 바·FC 밴드, 제어 그래프 설정 사용. 저장된 ET RoR도 전달.
프로파일 상세실측이 있으면 BT만 간략 표시. 없으면 목표 온도·시간으로 만든 합성 곡선 표시.저장된 BT / ET / RoR / ET RoR 전체 시간 구간을 읽기 전용으로 표시. 기록 이벤트·단계와 현재 표시 설정 적용.
결측·대체상세 미리보기에 합성 곡선이 실제 기록처럼 나타날 수 있음.켜 둔 ET·RoR·ET RoR 중 기록이 없는 채널은 — 표시. 실측이 없으면 기록 데이터 없음 안내. 히스토리의 합성 Target 대체도 제외.
범례·제어 영역히스토리 범례는 기록 존재 여부 중심. 출력이 숨긴 채널을 다시 드러낼 수 있음.범례는 데이터 존재와 표시 설정을 함께 반영. 표시할 제어 데이터가 없으면 빈 제어 영역을 예약하지 않음.
독립 표시

BT RoR를 꺼도 ET RoR는 유지

ET RoR는 BT RoR 표시 여부와 독립적으로 켤 수 있습니다. ET RoR만 켠 경우에도 오른쪽 축과 줌 좌표 계산용 여백을 확보합니다.

PDF 연계

숨긴 채널은 출력에서도 숨김

PDF 차트와 범례가 센서 표시 상태를 따릅니다. 화력·팬·드럼 제어선도 개별 표시 설정을 따릅니다. 다만 PDF의 기존 인쇄 규칙(0→Drop 구간, 고정 RoR 축 −10~20, 참조·단계 숨김 등)은 유지되어 화면과 축·구성이 완전히 같지는 않습니다.

사용 예 온도 130–240°C, RoR 0–15, ET 숨김으로 설정하면 히스토리와 상세 미리보기도 그 기준을 사용합니다. 음수 RoR와 95°C 표본은 화면 범위 밖에 있을 뿐 저장값은 그대로입니다. 이는 사용자 설정 예시이며 기본 RoR 범위는 −5–20입니다.

곡선의 의미 BT는 빈 온도, ET는 배기 온도, RoR는 온도 상승 속도입니다. 여기서 바뀌는 것은 작업자에게 보이는 곡선의 표현입니다. 프로파일의 기준 로스트에 저장된 측정값과 기록된 화력 명령은 별개로 보존됩니다. 상세 미리보기에는 히스토리의 제어 그래프가 없고, CSV의 기존 합성 대체 경로는 유지됩니다.

03 · BBP는 15분 창, 기준 로스트는 전체 데이터

BBP는 배출 뒤 다음 Charge 전까지 로스터의 열 상태를 관리하는 구간입니다. 현재 대기 측정과 기준 배치의 BBP·로스팅 곡선은 구분하며, 기준 곡선은 기준 Charge 경계에서 이어집니다.
