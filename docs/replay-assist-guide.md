# Replay Assist 운영 가이드

레퍼런스 배치의 화력 조작을 이번 배치에서 재생하는 기능(#300). Cropster Replay Assist 운영 권고와 동일한 원칙을 따른다.

## 운영 규칙

1. **재생 중 자리를 비우지 않는다.** 화력은 앱이 돌려도 안전 감시는 항상 로스터의 책임이다.
2. **개입은 앱에서만 한다.** Replay 체크를 해제하면 슬라이더가 풀리고, 다시 켜면 남은 구간부터 이어진다. 실측이 재생 지시에서 지속 이탈하면(컨트롤보드 직접 조작·타 소프트웨어·본체 자동 제어 — 원인은 구분하지 않는다) 재생이 자동 중지되고 이번 배치 동안 잠긴다 (#307).
3. **하루 첫 1–3배치는 주의 깊게 본다.** 기기 온도가 안정되기 전에는 레퍼런스와 거동이 달라 수동 보정이 필요할 수 있다.
4. **기센은 본체 Auto를 Manual로 둔다.** 본체 자동 제어와 병행하면 앱 지시가 덮인다.
5. **배출 시 화력은 설정("배출 시 화력 처리")을 따른다.** PID와 공용 정책이다(#316). `화력 0으로`면 Drop 마크 즉시 버너를 끄고, 기기가 안 따라오면 반영될 때까지 재시도한다. `현재 화력 유지`면 마지막 재생 값이 기기에 남는다 — 배출 후 화력 관리는 로스터 몫이다.

## 참고

- Cropster 권고 원문: [Using Gas control & Replay Assist](https://help.cropster.com/en/knowledge/using-gas-control/replay-assist)
- 외부 개입 감지(#307): Replay 마지막 확정 명령과 실측의 지속 이탈을 판정한다. settling(지시 미수렴) 구간은 제외하고, 허용 오차 초과가 연속되면 배치 종료까지 자동 해제·잠금. 이탈 원인(사람·본체 Auto·안전 인터락·타 소프트웨어)은 구분하지 못하며, 안전 목적에는 전부 중지 대상이라 충분하다.
