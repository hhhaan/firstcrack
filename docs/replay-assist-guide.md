# Replay Assist 운영 가이드

레퍼런스 배치의 화력 조작을 이번 배치에서 재생하는 기능(#300). Cropster Replay Assist 운영 권고와 동일한 원칙을 따른다.

## 운영 규칙

1. **재생 중 자리를 비우지 않는다.** 화력은 앱이 돌려도 안전 감시는 항상 로스터의 책임이다.
2. **개입은 어디서 하든 재생이 멈춘다.** 앱 슬라이더 조작은 즉시, 기기 조작반·타 소프트웨어·본체 자동 제어는 지속 이탈 감지(약 3초)로 자동 중지된다 — 원인은 구분하지 않는다 (#307). 다시 켜면 남은 구간부터 이어지고, 원인이 계속되면 다시 멈춘다.
3. **하루 첫 1–3배치는 주의 깊게 본다.** 기기 온도가 안정되기 전에는 레퍼런스와 거동이 달라 수동 보정이 필요할 수 있다.
4. **기센은 본체 Auto를 Manual로 둔다.** 본체 자동 제어와 병행하면 앱 지시가 덮인다.
5. **레퍼런스의 배출 이후 기록은 재생하지 않는다.** 컷오프는 레퍼런스 세션의 Drop 마크다(없으면 프로파일 duration). 배출 후 쿨다운 중 가스 조작은 이번 배치에 섞이지 않지만, 레퍼런스에 Drop 마크가 없으면 End 확정까지의 조작이 포함될 수 있으니 레퍼런스 배치는 Drop을 마킹한 세션으로 만든다.
6. **기센의 화력 0은 "끄기"가 아니다.** 클래식 기센(DB2 계열)에서 버너 세트포인트에 0을 쓰면 본체 자동 모드로 넘어간다(Artisan 메인테이너 확인, discussion #827). 그래서 앱은 이 기종에 0 대신 최소 1을 쓴다 — Artisan 수동 슬라이더와 같은 범위다. 진짜 가스 차단은 조작반이나 기계 인터락으로 해야 하며, 배출 후 자리를 뜰 때는 조작반을 확인한다. W6A PRO는 자동 전환값이 다르므로 0을 그대로 쓴다.
7. **배출 시 화력은 설정("배출 시 화력 처리")을 따른다.** PID와 공용 정책이다(#316). `화력 0으로`면 Drop 마크 즉시 버너를 끄고, 기기가 안 따라오면 반영될 때까지 재시도한다. `현재 화력 유지`면 마지막 재생 값이 기기에 남는다 — 배출 후 화력 관리는 로스터 몫이다.
8. **재생 중 타겟 프로파일을 바꿔도 켠 시점의 예정 조정은 유지된다.** Cropster와 같다(#377). 차트 오버레이는 새 타겟을 따라가지만 Replay 플랜은 끄기 전까지 바뀌지 않는다. 새 타겟으로 재생하려면 Replay를 껐다가 다시 켠다.

## 참고

- Cropster 권고 원문: [Using Gas control & Replay Assist](https://help.cropster.com/en/knowledge/using-gas-control/replay-assist)
- 외부 개입 감지(#307): Replay 마지막 확정 명령과 실측의 지속 이탈을 판정한다. settling(지시 미수렴) 구간은 제외하고, 허용 오차 초과가 연속되면 자동 중지 — write 없이 개입 값을 존중한다. 배치 잠금은 없다: 재개는 사람 토글로만 가능하고 감지가 즉시 재무장되므로, 원인이 지속되면 다시 걸린다. 이탈 원인(사람·본체 Auto·안전 인터락·타 소프트웨어)은 구분하지 못하며, 안전 목적에는 전부 중지 대상이라 충분하다.
